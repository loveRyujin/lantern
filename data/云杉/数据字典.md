# 云杉家居数据字典

工作区标识：`云杉`。公司名：云杉家居。表结构与星禾电商相同，数值和枚举不同。金额单位都是分。指标定义以《指标口径手册》为准，GMV 已经扣除退款。

## 生成

- 命令：`make seed`，或 `go run ./cmd/lantern-seed -root <目录> -seed 20261021`
- `make seed` 会删除并重建本机 Lantern 数据目录下的星禾、云杉两个工作区
- 使用 `-force` 时，先在数据目录里的临时目录生成星禾和云杉（目录名以 `.lantern-seed-` 开头）。两份都成功后才替换原来的工作区。生成失败时，原来的两个工作区保持不动。替换过程如果中断，原来的目录可能暂时在这个临时目录里；下次执行 `-force` 会清掉这些临时目录并重新生成，并把删掉的目录名写到标准错误。同一数据目录同时只能有一次 `-force`，拿不到 `.lantern-seed.lock` 就直接失败
- 默认随机种子：`20261021`。两个工作区共用这一个种子，再按工作区标识分流
- 同一种子两次生成，业务行的内容哈希相同
- 订单 `created_at` 落在 `2025-10-01T00:00:00Z`（含）到 `2026-10-01T00:00:00Z`（不含）
- 规模固定为用户 96、商品 30、订单 1200。每笔订单 1 到 3 行明细，明细数量 1 到 3
- 状态大约 88% 为已支付、7% 为已取消，其余为待支付。已支付订单里大约 8% 有一笔退款
- 退款时间比对应订单晚 1 到 20 天，可能晚于 2026-10-01

## analytics.db

手机号和邮箱不在这个库里。

### users

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | TEXT | 主键，形如 `ys-u-0001` |
| display_name | TEXT | 显示名 |
| city | TEXT | 城市。区域由口径手册按城市归类 |
| member_level | TEXT | `普通`、`会员`、`设计师` |

### products

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | TEXT | 主键，形如 `ys-p-0001` |
| name | TEXT | 商品名 |
| category | TEXT | `沙发`、`床具`、`桌椅`、`灯具`、`收纳` |
| price_cents | INTEGER | 标价，单位分 |

### orders

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | TEXT | 主键，形如 `ys-o-000001` |
| user_id | TEXT | 引用 `users.id` |
| created_at | TEXT | UTC，RFC3339，例如 `2026-09-12T08:30:00Z`。已支付订单以此作为支付时间 |
| status | TEXT | `已支付`、`已取消`、`待支付` |
| amount_cents | INTEGER | 订单金额，等于明细 `qty * unit_price_cents` 之和 |

### order_items

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | TEXT | 主键，形如 `ys-i-000001` |
| order_id | TEXT | 引用 `orders.id` |
| product_id | TEXT | 引用 `products.id` |
| qty | INTEGER | 数量 |
| unit_price_cents | INTEGER | 成交单价，单位分，可以低于标价。折扣不单列 |

### refunds

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | TEXT | 主键，形如 `ys-r-000001` |
| order_id | TEXT | 引用 `orders.id`。只连到已支付订单 |
| created_at | TEXT | 退款时间，UTC，RFC3339 |
| amount_cents | INTEGER | 退款金额，大于 0，不超过订单金额 |
| reason | TEXT | `尺寸不合适`、`有色差`、`物流破损`、`七天无理由`、`不想要了` |

## sensitive.db

### user_contacts

与 `users.id` 一一对应。两个库没有跨库外键。

| 列 | 类型 | 说明 |
| --- | --- | --- |
| user_id | TEXT | 主键，等于 `analytics.users.id` |
| phone | TEXT | 11 位手机号原文 |
| email | TEXT | 邮箱原文，形如 `ys-u-0001@yunshan.example` |

## 没有的字段

渠道、注册时间、单独的支付时间、折扣、区域都不单列。区域用 `users.city`。渠道问数见《指标口径手册》。
